## 🚀 How to Run Locally

You can open the website directly in any modern browser:

### Option A: Direct Open
Double click `index.html` or drag it into any web browser (Chrome, Edge, Safari, Firefox).

### Option B: Local Python Server (Recommended)
```bash
python -m http.server 8080
```
Then visit:
`http://localhost:8080`

### Option C: Personalized Direct Link Examples
- For Family: `http://localhost:8080/?to=The%20Kapoor%20Family&from=Biswajit&blessing=prosperity`
- For Colleagues: `http://localhost:8080/?to=Esteemed%20Partners&from=Biswajit&blessing=victory`
- For Wisdom: `http://localhost:8080/?to=Aarav&blessing=wisdom`
